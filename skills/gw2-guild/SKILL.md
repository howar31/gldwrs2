# gw2-guild

Commands under `gw2 guild`.

## Commands

- `gw2 guild` — Guild info, roster, and treasury
- `gw2 guild permissions [flags]` — Fetch guild permissions
  - `--all` — fetch every entry (explicit; may be large)
  - `--ids <string>` — comma-separated ids (omit to list ids)
- `gw2 guild search` — Find a guild's id by name
- `gw2 guild upgrades [flags]` — Fetch guild upgrades
  - `--all` — fetch every entry (explicit; may be large)
  - `--ids <string>` — comma-separated ids (omit to list ids)

See `gw2-shared` for auth setup and global flags.
