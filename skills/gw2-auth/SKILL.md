# gw2-auth

Commands under `gw2 auth`.

## Commands

- `gw2 auth list` — List stored profiles (never prints keys)
- `gw2 auth remove` — Remove a stored profile
- `gw2 auth set [flags]` — Store an API key under a profile
  - `--key <string>` — the API key value

See `gw2-shared` for auth setup and global flags.
