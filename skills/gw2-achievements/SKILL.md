# gw2-achievements

Commands under `gw2 achievements`.

## Commands

- `gw2 achievements [flags]` — Achievements, categories, groups, and dailies
  - `--all` — fetch every entry (explicit; may be large)
  - `--ids <string>` — comma-separated ids (omit to list ids)
- `gw2 achievements categories [flags]` — Fetch achievements categories
  - `--all` — fetch every entry (explicit; may be large)
  - `--ids <string>` — comma-separated ids (omit to list ids)
- `gw2 achievements daily` — Today's daily achievements
- `gw2 achievements daily tomorrow` — Tomorrow's daily achievements
- `gw2 achievements groups [flags]` — Fetch achievements groups
  - `--all` — fetch every entry (explicit; may be large)
  - `--ids <string>` — comma-separated ids (omit to list ids)

See `gw2-shared` for auth setup and global flags.
